Sakura counter acquisition and exact target roster

Direct acquisition: 32 representative counters appear in Combat creative and the four weapon chest tables, and can roll on Glitch Bow. All 133 exact IDs remain registered and player-selectable by retuning a held counter using /sakura counter. Retuning is free and therefore provides every target variant after acquiring one counter; this deliberately changes progression and should be reviewed for balance.
The matching representative below shares school, shape, palette and runic flag. Retuning changes the actual ID, so its own precise target, damage, name, runic flag and ward still apply. Legacy IDs were not deleted. The ten previous common-blade legacy IDs are now retunable rather than direct drops. Glitch Bow saved index order is unchanged.
